## Objective
Convert raw student marks data into a Pandas DataFrame, inspect NumPy array properties (shape, size, and dimensions), and perform basic matrix operations using NumPy.

## Files Included

## Key Concepts & Operations Covered
- **Pandas DataFrame Creation:** Converting a Python dictionary of student marks (`Maths`, `Stats`, `DSA`) into a structured DataFrame (`df`)
- **NumPy Array Properties:** Extracting numerical marks into a 2D NumPy array and checking `.shape`, `.size`, and `.ndim`
- **Matrix Operations:** Addition (`A + B`), subtraction (`A - B`), element-wise multiplication (`A * B`), matrix product (`A @ B`), transpose (`A.T`), and matrix inverse (`np.linalg.inv(A)`) with singular-matrix handling (`np.linalg.LinAlgError`)
